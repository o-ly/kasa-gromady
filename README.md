# Каса Громади

Програма для касира церковної громади: суботні надходження, витрати, залишки по відділах і щомісячний звіт для конференції.

## Завантажити

- **Mac:** [KasaGromady-mac.zip](https://github.com/o-ly/kasa-gromady/releases/latest/download/KasaGromady-mac.zip) — для Mac з процесором Apple (M1 і новіші)
- **Windows:** [KasaGromady-windows.exe](https://github.com/o-ly/kasa-gromady/releases/latest/download/KasaGromady-windows.exe) — Windows 10/11

Усі версії — на сторінці [Releases](https://github.com/o-ly/kasa-gromady/releases).

## Перший запуск

**Mac.** Розпакуйте архів і перенесіть «Каса Громади» в папку «Програми». Перший раз відкрийте через правий клик → «Відкрити». Якщо macOS не дає відкрити: Системні параметри → Конфіденційність і безпека → «Все одно відкрити».

**Windows.** Покладіть файл у папку або на флешку, де лежатиме база. Якщо Windows покаже «Захистила ваш ПК»: «Докладніше» → «Все одно запустити».

Логін і пароль видає адміністратор громади.

Програма працює без інтернету. Дані зберігаються в одному зашифрованому файлі на вашому комп'ютері або флешці.
